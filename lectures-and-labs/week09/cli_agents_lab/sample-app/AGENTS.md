# Agent Instructions

## Running Tests
- Run the tests using:
  python -m unittest discover -v

## Rules
1. Never change a test's expected value just to make a test pass.
2. If a test fails, fix the implementation code instead of changing the test.
3. Use only the Python standard library. Do not install external packages.
4. After running any command, check its output before proceeding to the next step.
5. When fixing bugs, make the smallest necessary change.
6. Do not modify test files unless explicitly required for a legitimate reason.
